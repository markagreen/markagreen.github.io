# Wedding website

This folder is designed to live at:

`https://markagreen.github.io/wedding/`

It is intentionally kept separate from the main personal website so that it remains private. 

## Files

- `index.html` — welcome/home page
- `schedule.html` — wedding-day timetable
- `travel.html` — travel and directions
- `accommodation.html` — accommodation
- `story.html` — your story
- `faq.html` — expandable FAQ
- `css/style.css` — all styling
- `js/site.js` — mobile navigation and countdown
- `images` — all photographs and images for the website in this folder.

The entire folder will be removed after the wedding.
